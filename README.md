# Banking Analytics - Power BI Case Study
## Executive Summary:
This case study was developed entirely in **Power BI** using a **synthetic randomized banking dataset** that does not represent any real bank or real-world business situation.

Using **Power Query**, I cleaned and prepared the data, built the **semantic data model** in **Model View**, and set up the required **relationships and cardinalities** between the tables. I then created an interactive dashboard with **Overview, Loan Performance, Branch Performance, and Risk & Fraud** pages to visualize and analyze key banking metrics and trends.

The final project is fully functional, connected, and tested, combining **data preparation, modeling, visualization, and analysis** in line with the core **PL-300 skills**.
